## 📖 About The Project

This project is a modern cinematic temple website created for:

### 🛕 Mandathra Sree Muthappan Bhagavathi Temple  
Located in Koolimuttam, Thrissur, Kerala.

The website is designed to digitally represent:
- Kerala spiritual heritage
- Muthappan Theyyam traditions
- Sacred rituals & offerings
- Temple festivals
- Devotional atmosphere
- Cultural storytelling

The experience combines:
- Traditional Kerala aesthetics
- Modern cinematic UI/UX
- Smooth animations
- Responsive design
- Premium spiritual branding
